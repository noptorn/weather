Weather Publisherกลับหน้าหลัก

นโยบายความเป็นส่วนตัว

ปรับปรุงล่าสุด 25 ตุลาคม 2026

นโยบายนี้อธิบายการจัดการข้อมูลของ Weather Publisher เครื่องมือบนเครื่องของผู้ดูแลเพจสำหรับเตรียมสื่อและส่งคำขอเผยแพร่ผ่าน API ของ Meta และ YouTube เว็บไซต์นี้ใช้แสดงข้อมูลแอปและเอกสารเท่านั้น ไม่มีแบบฟอร์มรับวิดีโอ รหัสผ่าน หรือ Access Token

ผู้ดูแลและการติดต่อ

ผู้ดูแล Weather Publisher เป็นผู้ดูแลเพจพยากรณ์อากาศ ล่าสุด ล่วงหน้า สามารถติดต่อผ่านช่องทางของเพจนี้เพื่อสอบถามนโยบายหรือขอความช่วยเหลือเรื่องข้อมูล ห้ามส่งรหัสผ่าน Access Token หรือ App Secret ผ่านข้อความติดต่อ

ข้อมูลที่ใช้และวัตถุประสงค์

แอปใช้ชื่อและรหัสบัญชีหรือเพจ การตั้งค่าการเชื่อมต่อ ชื่อไฟล์สื่อ ข้อความคำบรรยาย เวลาที่เลือกเผยแพร่ รหัสโพสต์ และสถานะตอบกลับจากแพลตฟอร์ม เพื่ออัปโหลด ตั้งเวลา ติดตามงาน และแสดงประวัติการเผยแพร่ เมื่อผู้ใช้สั่งคอมเมนต์สินค้า แอปใช้รหัสโพสต์ ชื่อสินค้า ลิงก์สินค้า และรหัสความคิดเห็นเพื่อส่งความคิดเห็นไปยังโพสต์ที่เลือกและบันทึกประวัติการทำงาน

แอปใช้สิทธิ์ที่ผู้ใช้อนุญาตเพื่อค้นหาเพจที่จัดการ อ่านข้อมูลที่จำเป็นเกี่ยวกับเพจและโพสต์ สร้างโพสต์ และจัดการความคิดเห็นตามการทำงานที่ผู้ใช้เลือก ไฟล์สื่อถูกเลือกจากเครื่องโดยผู้ใช้

ที่เก็บข้อมูล

การตั้งค่าและคิวงานเก็บในพื้นที่จัดเก็บของเบราว์เซอร์บนเครื่อง ประวัติโพสต์และความคิดเห็น Facebook บางส่วนเก็บเป็นไฟล์บนเครื่องของผู้ดูแล Access Token จากขั้นตอนเชื่อมต่อเก็บใน browser session หรือหน่วยความจำของ local server ส่วนข้อมูลลับที่เจ้าของเครื่องตั้งค่าไว้ในไฟล์บนเครื่องยังอยู่จนกว่าเจ้าของเครื่องจะลบหรือเปลี่ยนค่า

ระหว่างอัปโหลด Reel local server รับไฟล์ชั่วคราวเพื่อส่งต่อไป Meta โค้ดพยายามลบไฟล์ชั่วคราวเมื่อคำขอสิ้นสุด ไฟล์ต้นฉบับที่ผู้ใช้เลือกยังคงอยู่ในเครื่อง การล้างข้อมูลเบราว์เซอร์ไม่ลบไฟล์ต้นฉบับหรือไฟล์ประวัติบนเครื่องโดยอัตโนมัติ

การส่งต่อให้แพลตฟอร์ม

เมื่อผู้ใช้สั่งงาน แอปส่งสื่อ ข้อความ เวลาเผยแพร่ และข้อมูลยืนยันสิทธิ์ที่จำเป็นไปยังแพลตฟอร์มที่เลือก เช่น Meta หรือ Google/YouTube แพลตฟอร์มเหล่านี้จัดการข้อมูลตามนโยบายของตน ข้อมูลบนเพจอาจเป็นสาธารณะตามการตั้งค่าและสถานะการเผยแพร่ การเชื่อมต่อ TikTok ยังไม่เปิดใช้งานในเวอร์ชันนี้

การเก็บรักษาและสิทธิในการลบ

ข้อมูลบนเครื่องเก็บไว้จนกว่าผู้ดูแลจะลบผ่านฟังก์ชันที่เกี่ยวข้อง ล้างข้อมูลเบราว์เซอร์ หรือลบไฟล์ที่เกี่ยวข้องเอง การเพิกถอนสิทธิ์หรือหยุดใช้แอปไม่ลบโพสต์ ความคิดเห็น หรืองานที่แพลตฟอร์มรับไปแล้ว และไม่ลบสำเนาในเครื่องโดยอัตโนมัติ อ่านขั้นตอนที่หน้าคำแนะนำการลบข้อมูล หรือติดต่อผู้ดูแลผ่านเพจ

เว็บไซต์เอกสารนี้

เว็บไซต์นี้ไม่มีระบบสมัครสมาชิกและไม่ใช้เครื่องมือวิเคราะห์ผู้เข้าชมที่เราเพิ่มขึ้นเอง ผู้ให้บริการโฮสต์อาจประมวลผลข้อมูลการเชื่อมต่อพื้นฐานเพื่อให้บริการและรักษาความปลอดภัยตามนโยบายของผู้ให้บริการ

การเปลี่ยนแปลง

เมื่อวิธีจัดการข้อมูลหรือการเชื่อมต่อเปลี่ยนไป จะปรับปรุงหน้านี้และแสดงวันที่ปรับปรุงล่าสุด

English summary. Weather Publisher is a local tool for managing authorized social media publication. It uses account/page identifiers, selected media, captions, schedules, post and comment identifiers, and connection credentials. Browser settings and queue records remain on the user's device; local files also retain Facebook publishing/comment history. Connected tokens are held in session storage or server memory; credentials manually configured in local files remain until removed. User-requested content and necessary credentials are sent to the selected Meta or Google/YouTube APIs. This documentation website does not accept account credentials or media uploads. Contact the linked Facebook Page for privacy or deletion assistance; do not send passwords or tokens. See the data deletion page for instructions.
